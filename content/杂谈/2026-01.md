- 使用命令 `uv add langchain-tavily` 下载对应依赖；
- 从 [Tavily API Platform]() 获取免费的 `api key` 并添加到 .env 环境配置文件。

        for r in parsed.get("results", [])
    ]

    # self-define a function "format_tool_result"
    return ...

tavily_search = StructuredTool.from_function(
    func=tavily_search_func,
    coroutine=tavily_search_func,
    name="tavily_search",

    args_schema=TavilySearchInput,

## 2026-01-27

- tag: #python #json
- title: 使用 Python 转换 JSON 格式
- description: Python 中的 JSON 格式转换与处理
- date: 2026-01-27

Pydantic 提供了 `model_dump` 方法来实现类似于 `asdict` 方法的转换字典：

```python
from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int
    email: str
user = User(name="Bob", age=30, email="hi@hello.com")
# ✅ 主要方法
user.model_dump()  # {'name': 'Bob', 'age': 30, 'email': 'hi@hello.com'}
user.model_dump_json()  # '{"name":"Bob","age":30,"email":"hi@hello.com"}'
user.model_dump(exclude={'email'})  # 排除字段
user.model_dump(include={'name', 'age'})  # 包含目的字段
# ✅ 使用字段别名
class UserWithAlias(BaseModel):
    name: str = Field(alias='userName')
    age: int
u = UserWithAlias(userName="Alice", age=30)
print(u.model_dump(by_alias=True))

```

## 2026-01-27

- tag: #python #langchain
- title: 基于 LangChain 的 LLM 结构化输出响应
- description: 通过 Pydantic 自定义响应类型并且传入 invoke 方法实现自定义结构化输出。
- date: 2026-01-27

LangChain 支持结构化输出，但是 `output_schema` 必须是 Pydantic 类型（不能是 dataclass 类型），同时还必须给 llm 添加 `method="json_mode"` 参数。

参考代码：

```python
from langchain_openai import ChatOpenAI
from langchain_core.messages import(
    AIMessage,
    HumanMessage,
    SystemMessage,
    BaseMessage,
)

llm = ChatOpenAI(...)
messages: list[BaseMessage] = []

system_prompt = ...

# 1. 处理 System Prompt
messages.append(SystemMessage(content=system_prompt))

# 2. 处理 User Prompt
messages.append(HumanMessage(content=prompt))

# 3. 声明 Response Schema
llm_with_structured_output = llm.with_structured_output(
    output_schema, # <- 传入一个 Pydantic 类型
    method="json_mode"
)

# 4. 调用 LLM
# 伪代码（实际调用在异步函数 async def func 中调用）
response: AIMessage = await llm_with_structured_output.ainvoke(
    messages
)

```

## 2026-01-26

- tag: #python #Hash
- title: Python 缓存管理和哈希化处理
- description: 在学习 [dexter 工具调用缓存](https://github.com/virattt/dexter/blob/00e1aa69/src/utils/context.ts) 内容时学习到一种哈希化方法, 目的是为了实现缓存管理和文件系统组织.
- date: 2026-01-26

使用到 `hashlib`, `json` 两个库文件, 将参数字典序列化为 JSON 字符串并转换为哈希值:
```python
def _hash_args(self, args: dict[str, Any]) -> str:
    # 按键排序并序列化为JSON字符串
    sorted_keys = sorted(args.keys())
    args_str = json.dumps({k: args[k] for k in sorted_keys}, separators=(',', ':'))

    # 计算MD5哈希值并取前12位
    hash_obj = hashlib.md5(args_str.encode('utf-8'))
    return hash_obj.hexdigest()[:12]
```

## 2026-01-20

- tag: #python
- title: 分享一个管理配置文件的方法
- description: 文件路径、文件类型（反射）如果太多或比较复杂，还是使用 `config.ini` 配置文件来管理比较养眼，yaml 文件感觉内容一多就有些繁琐（不过也很不错）
- date: 2026-01-20

`config.ini` 文件的基本语法是通过下面的格式来管理的：
```ini
[Classification]
key = value
```

我们可以通过 `configparser` 库来读取内容：
```python
import configparser

# 假设 config.py 和 config.ini 在同一目录层级
_config_file = Path(__file__).parent.parent / "config.ini"
_config = configparser.ConfigParser()
_config.read(_config_file)

VALUE = _config.get(
    "Classification",
    "key",
    fall_back="value" # 默认值
)
```
